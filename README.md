# Overseer

A server-side Minecraft mod with a built-in web dashboard: live data and history from
your world and its mods, on desktop and phone.

- **Flux Networks**: networks, devices, energy flow, buffer, forecasts
- **Applied Energistics 2** (planned): storage, crafting CPUs, trends, deficits
- **Server**: TPS, MSPT, players

Players log in with a code they confirm in-game and only see what the mods' own
permission rules allow. Mods that are not installed are skipped.

> Status: early development (milestone M0). Targets Forge 1.20.1.
